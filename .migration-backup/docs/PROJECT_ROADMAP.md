# MobileMorocco - Project Roadmap

## Project Overview
MobileMorocco is a comprehensive platform connecting buyers and sellers of mobile phones, accessories, and repair equipment in Morocco. The platform supports multiple user types (Importers, Technicians, Customers) with different subscription levels and features.
